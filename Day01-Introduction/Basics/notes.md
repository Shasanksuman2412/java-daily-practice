# Day 01 - Introduction & Hello World

## What I learned
- Java is a compiled, object-oriented language that runs on the JVM.
- Every Java program needs at least one class, and execution starts from `public static void main(String[] args)`.
- `javac HelloWorld.java` compiles the file; `java HelloWorld` runs the compiled class.

## Commands I ran
```bash
javac HelloWorld.java
java HelloWorld
```
